# AI_ERROR_LOG — Журнал ошибок и уроков

> Сверяться перед написанием кода/дебагом. Формат: [Дата] Ошибка → Корневая причина → Как исправили.
> После решения сложного бага — предложить пользователю внести запись сюда.

## Ограничения среды (постоянные)
- **Windows PowerShell 5.1**: нет `&&`/`||` (использовать `;` и `if ($?)`); нет ternary/`??`. Не редиректить stderr нативных exe.
- **Кириллица в SQL через stdin** (docker exec psql) может битьcя → для DELETE/UPDATE фильтровать по **числовым client_id** (узнать `SELECT client_id,name FROM core.dim_client`), не по строкам.
- **Локальный Python 3.6** не подходит — весь код только в контейнере app (3.11).
- **Docker Desktop** после перезагрузки ПК не стартует сам → запустить вручную (`& "C:\Program Files\Docker\Docker\Docker Desktop.exe"`), затем `docker compose start`.
- **AskUserQuestion**: не вставлять «сырые» `\uXXXX` — писать кириллицу напрямую, иначе InputValidationError.
- **152-ФЗ**: ПДн (ИНН ИП, ФИО, адреса физлиц) — только на сервере в РФ. Зарубежный сервер для PD-слоя нельзя.

- **[2026-07-11] 🔴 ТЕКУЩИЕ ОСТАТКИ ЗАВЫШЕНЫ В 2.5 РАЗА** (нашёл руководитель: сайт 9.3млн ₽ по НеоФарм vs 7млн в Sales Retail) → причина: `marts.v_stock_latest` брала `DISTINCT ON (client_id, tt_id, sku_id) ... Итог: НеоФарм 8647шт/7 145 594₽ = совпало с Sales Retail; всего остатки 104729→41820 шт. УРОК: «последний снимок» = MAX(snapshot_date) НА КЛИЕНТА, никогда не per-SKU/ТТ (это carry-forward, не факт).
